# Deferred-proof registry for theorems that are believed true but not yet
# closed.  Complement of `docs/admitted-counterexamples.txt`.
#
#   Tier 1: unregistered `Admitted` -- BUILD FAILURE.
#   Tier 2: counterexample registry -- statement is too strong.
#   Tier 3: THIS file -- statement is believed true; proof is pending.
#
# `scripts/check_admitted.sh` requires every `Admitted` in theories/ and
# theories-flocq/ to appear in EXACTLY ONE of the two registries.
#
# Format (one live entry per non-comment, non-blank line):
#
#   file:theorem_name | proof_structure_doc | section_references
#
# Entries are TEMPORARY -- they come off when the proof lands.  Removing
# an entry without closing the theorem violates the epistemic invariant.
#
# LIVE: none
#
# Discharged / archived entries: git history of this file, and
# docs/history/deferred-proofs-registry-archive.md.
