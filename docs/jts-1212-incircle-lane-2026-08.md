## §1 — What #1212 changes

`TrianglePredicate.isInCircleRobust`:

1. Evaluate the Shewchuk in-circle determinant in **double** (coords translated
   so `P` is the origin — same matrix as corpus `inCircle_R`).
2. Stage A error bound  
   `iccerrboundA = (10 + 96·ε)·ε`, `ε = 2⁻⁵³`  
   scaled by the matrix permanent; if `|disc| > errBound`, return `disc > 0`.
3. Else fall back to existing **`isInCircleDDNormalized`** (DD extended precision).

Also: `Vertex.isCCW` → `Orientation.index` (robust CCW).

Claims to close/supersede: JTS #20, #298, #310, #1190 (#1138), GEOS #1286, PR #311.

## §5 — Implications for JTS / NTS

1. **#1212 filter shape is consistent** with corpus Stage A discipline (same
   `iccerrboundA` constant family as Shewchuk; uncertain on the knife edge).
2. **Do not** treat double `disc` alone as Delaunay ground truth near
   cocircularity — use DD / exact / Rocq `INCIRCLE_SIGN`.
3. Corpus pins remain the **certified** regression set; JTS test sites are
   **open** (no Qed EXPECTED) but oracle-signed for differential use.
4. NTS port of #1212 should re-run this script against the same table once
   `TrianglePredicate` lands in NTS.
