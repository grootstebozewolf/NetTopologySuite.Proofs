This addendum does not rewrite the Decision, Parks table, or first-cook scope of ADR-0007.

**Dual-home.** The constructor kernel lives on the host lane. A binary64 cook is a realisation of `ℰ`, not a second kernel and not a reason to take `SheetHenCook.v` off `_CoqProject`.

Host / `make host` / three-axiom / Stdlib keeps: Sheet, Hen, Egg, Chicken, Cook / `ℰ`, Decline, View; first-cook inhabitance (chord–chord, `MkCirc`, `MkClothoid`); ρ *parks* (`LoopObligation`, leftover-bag named QEX); sidecar fences (`I_ok_*` Hit ≠ host `I_ok`).

Full lane may grow a **b64 cook**: a cook whose Hit may mint a hen from binary64 (`B2R`, `snap_round`, hot-pixel lattice). That realisation does not remint host `I_ok`, does not move ρ parks, and does not discharge `LoopObligation`. A future discharging ρ on full is work, not this Accepted fact.

**Forbidden.** Dragging `SheetHenCook.v` (or the first-cook / ρ-park / sidecar-fence cone) into `_CoqProject.full` only. Calling a flocq file a cook because it mentions `I_ok`. Treating sidecar Hit as host Γ.
