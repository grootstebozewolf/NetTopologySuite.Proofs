# Counterexample registry for theorems that are false as stated.
# Complement of `docs/admitted-deferred-proofs.txt`.
#
#   Tier 1: unregistered `Admitted` -- BUILD FAILURE.
#   Tier 2: THIS file -- statement is too strong; a weaker form is the
#           most that is achievable.  Permanent until the theorem is
#           re-scoped.
#   Tier 3: deferred-proof registry -- statement is believed true.
#
# `scripts/check_admitted.sh` requires every `Admitted` in theories/ and
# theories-flocq/ to appear in EXACTLY ONE of the two registries.
#
# Format (one live entry per non-comment, non-blank line):
#
#   file:theorem_name | counterexample_doc | section_references
#
# Removing an entry without closing or re-scoping the theorem violates
# the epistemic invariant.
#
# LIVE: none
#
# Resolved / aborted historical statements: git history of this file.
